LandSurf uses French national geoscience evidence to screen mapped geology and nearby subsurface records, and can use DVF+ transaction evidence for land-value context only when the available sample is strong enough.

Evidence used for a French plot

BRGM geology

InfoTerre geological evidence provides national mapped ground context. Map units describe the area and are not treated as a substitute for a geotechnical investigation.

BSS boreholes

The Banque du Sous-Sol provides nearby borehole and underground-work records. Their observations remain tied to their own locations.

DVF+ market evidence

LandSurf can use geolocated DVF+ transaction evidence for an indicative land-only range when a defensible buildable-land sample exists.

Fail closed on weak value evidence

If the DVF+ sample is insufficient, LandSurf shows no generic French land value rather than manufacturing a plausible number.

Scope of the result

Land only.

Any indicative value concerns the land component and excludes buildings and other improvements. Binding planning, title, parcel boundary and engineering decisions still require the competent French source or professional.
